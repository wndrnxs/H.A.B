# 우리집 가계부 (H.A.B — Household Account Book)

두 사람과 강아지 한 마리를 위한 가계부입니다.
빌드 도구 없이 정적 파일만으로 돌아가고, PC 브라우저와 휴대폰에서 모두 씁니다.

## 할 수 있는 것

| 화면 | 내용 |
| --- | --- |
| **대시보드** | 이번 기간 수지, 순자산·총자산·카드 미결제, 최근 12개월 **자산 흐름** 그래프, 분류별 비중 도넛, 예산 진행, 최근 내역 |
| **내역** | **일 · 주 · 월** 단위로 기간을 옮겨 가며 조회, 일자별 지출 막대(막대를 누르면 그날로 이동), 유형·사람·분류·결제수단·검색어로 거르기 |
| **통계** | 분류별 지출(비중과 지난 기간 대비 증감), 사람별 지출, 결제수단별 지출, 최근 12개월 수입·지출 비교 |
| **자산** | 순자산 추이, 계좌별 잔액, 자산 구성 |
| **설정** | 구성원·분류·예산·계좌 편집, 백업 내보내기/불러오기, 테마 |

그 밖에:

- **함께 쓰는 사람** — 기본값은 `나 · 예비신부 · 강아지` 셋이고, 지출마다 누구 몫인지(또는 `공동`) 남길 수 있습니다. 통계에서 강아지에게 들어간 돈이 따로 잡힙니다.
- **예시 데이터** — 처음 열면 최근 3개월치 예시 내역이 들어 있습니다. 모두 `예시` 꼬리표가 붙어 있고 대시보드 배너나 설정에서 한 번에 지웁니다.
- **다크 모드** — 기기 설정을 따라가고, 설정에서 고정할 수도 있습니다.
- **홈 화면에 추가(PWA)** — 앱처럼 열리고, 껍데기가 캐시되어 신호가 약한 곳에서도 뜹니다.

## 바로 써보기

### 1. 로컬에서

```bash
git clone https://github.com/wndrnxs/H.A.B.git
cd H.A.B
npx http-server . -p 8080     # 또는 python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 을 엽니다.
(모듈 스크립트를 쓰기 때문에 `index.html` 을 파일로 직접 열면 동작하지 않습니다. 반드시 서버로 띄우세요.)

### 2. 휴대폰에서도 열리게 — GitHub Pages

1. 이 저장소의 **Settings → Pages → Source** 를 `GitHub Actions` 로 바꿉니다.
2. `main` 브랜치에 올리면 `.github/workflows/pages.yml` 이 자동으로 배포합니다.
3. `https://wndrnxs.github.io/H.A.B/` 에 접속한 뒤
   - iPhone: 공유 → **홈 화면에 추가**
   - Android: 메뉴 → **앱 설치**

## 데이터는 어디에 저장되나

| 실행 위치 | 저장소 | 특징 |
| --- | --- | --- |
| GitHub Pages·로컬 서버 | 브라우저 `localStorage` | 기기 안에만 남습니다. PC와 폰이 각각 따로 쌓입니다. |
| Claude 아티팩트 | 아티팩트 공유 문서 저장소 | 같은 계정으로 연 PC·폰이 **같은 장부**를 봅니다. |

같은 코드가 실행 환경을 보고 알아서 고릅니다 (`assets/store.js` 의 어댑터).
사이드바(모바일은 설정 화면)에 지금 어느 쪽인지 표시됩니다.

**두 사람이 각자 휴대폰에서 실시간으로 함께 쓰려면** 서버가 필요합니다.
`assets/store.js` 의 어댑터는 `load / putConfig / putItems / putMonth / clear / subscribe`
여섯 가지만 구현하면 되도록 잘라 두었으니, Supabase·Firebase 같은 것을 하나 더 끼우면 됩니다.
그 전까지는 **설정 → 데이터 → 백업 복사 / 불러오기** 로 주고받을 수 있습니다.

## 폴더 구조

```
index.html                 정적 호스팅용 문서
artifact.html              Claude 아티팩트용 문서 (같은 assets 를 씁니다)
assets/
  util.js                  날짜·금액·DOM 유틸
  store.js                 데이터 모델, 저장 어댑터, 예시 데이터
  charts.js                SVG 차트 (영역·막대·묶음막대·도넛)
  views.js                 다섯 화면과 입력 시트
  app.js                   부팅, 사이드바·상단바·하단 탭
  styles.css               테마 토큰과 레이아웃
sw.js                      오프라인용 서비스 워커
manifest.webmanifest       홈 화면 설치 정보
tools/make-icons.mjs       아이콘 PNG 생성기 (node tools/make-icons.mjs)
```

의존성이 없습니다. `npm install` 할 것도, 빌드할 것도 없습니다.

## 손대기 좋은 곳

- **기본 분류·계좌·구성원** — `assets/store.js` 의 `defaultConfig()`. 앱을 쓰면서 설정 화면에서 고쳐도 됩니다.
- **예시 데이터** — 같은 파일의 `sampleTxns()`. 결혼 준비 항목, 반려견 지출, 카드 대금 결제까지 들어 있습니다.
- **색과 글꼴** — `assets/styles.css` 맨 위의 토큰. 차트 색 `--s1`~`--s8` 은 색각 이상에서도 구분되도록 검증된 배열입니다.
